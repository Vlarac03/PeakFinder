# entry/

Projecte de DevEco Studio per al rellotge (JS Lite Wearable), amb la mateixa estructura que [PadelCounter](https://github.com/Vlarac03/PadelCounter).

**Versió actual: 0.1.0, prototip de prova de sensors.** Només mostra el rumb de la brúixola, la posició GPS i la pressió del baròmetre, amb l'estat (OK o codi d'error) de cada un. Encara no identifica cims.

- `src/main/config.json`: paquet `com.vlarac.peakfinder`, permís de localització i versió.
- `src/main/js/MainAbility/pages/index/`: `index.hml`, `index.css` i `index.js`.

Procediment de prova a [`../docs/prova-sensors.md`](../docs/prova-sensors.md).
