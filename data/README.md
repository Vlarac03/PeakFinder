# Dades de cims

Aquí hi anirà l'script que genera la base de dades compacta de cims a partir d'OpenStreetMap.

Previst:

- `build_peaks.py`: descarrega els `natural=peak` de la zona (Pirineus i Catalunya), els neteja i els escriu en JSON compacte dividit per quadrícules.
- `raw/` i `.cache/` estan al `.gitignore`: les descàrregues brutes no es pugen.
